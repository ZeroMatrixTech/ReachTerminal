# IBKR 行情会话 HTTP 400 排查与修复

2026-10-16，本机复现：账户 SSO 有效，但行情 `authenticated=false`。行情初始化返回 HTTP 200、`authenticated=false`，随后账户准备曾返回 HTTP 400；标的搜索在终端返回 400，其上游实际为认证拒绝。不能仅凭网页登录成功或初始化接口 HTTP 200 判定行情就绪。

诊断时执行了固定不抢占的初始化请求，以及一次旧版 Gateway 会话恢复探测；随后只读账户握手和状态复查确认恢复。`reauthenticate` 已被官方弃用，本修复不将其加入运行时路由、不设置自动回退。不能据这次顺序探测证明单个探测请求是恢复的唯一原因。

恢复后的实际验收：行情已认证且已连接；IBM 搜索返回 22 条合约；行情准备成功；近月历史日线返回 21 根。未进行交易，未导入账户余额、持仓或交易流水。

代码修复：

- 初始化后等待至少两秒，读取 `/iserver/accounts` 完成 Gateway 的账户握手确认。
- 初始化未就绪时保留初始化状态，在三分钟窗口内按至少五秒间隔检查账户握手；不重复抢占或自动重新发起行情初始化。
- 空账户结果不能标记行情准备成功；认证与账户就绪尚未确认时不启用“准备行情”。
- 错误显示接口路径、上游 HTTP 状态和处理建议；账户 ID、查询参数及上游原始响应均不回显。
- 保留 SSO 每分钟最多一次、设备绑定和合成网关 5001 隔离。

官方依据：[初始化后的账户读取](https://www.interactivebrokers.com/docs/web-api/authentication/trading)、[弃用旧恢复接口](https://www.interactivebrokers.com/docs/web-api/changelog/2024/2/5)。
