## 范围与限制

本版覆盖现金股票，采用策略内独立 FIFO。收益指数为日频现金流调整近似，具体口径见数据契约。全球标的和多币种可导入，免费全球基本面、实时行情、新闻和分析师一致预期不保证覆盖。

Flex 仅验证合成样本；尚未使用用户真实 IBKR 报表验收。不支持的资产和事件明确拒绝。SEC 文件导入已验证，联网抓取需要用户配置联系邮箱，未在本次调用外部 SEC 服务验收。

没有实时 IBKR Gateway 连接、订单接口、期权定价、保证金计算或组合保证金复刻；没有压力或大规模性能测试。当前界面均明确标注合成演示数据。

## DeepSeek 协作

两批并发，共 4 次实际请求，用于核算契约、基本面契约和反例审查。最终代码由主代理编写与验证。接受了披露时点、来源追溯、CIK 绑定等有效建议；纠正了其 FIFO 样例中的数值错误，并拒绝未能由源码或测试支持的缺陷判断。API 完成不作为正确性依据。
