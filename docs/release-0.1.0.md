# ReachTerminal v0.1.0 发布验收

本地浏览器前端 + C++20 + PostgreSQL。只读券商连接；没有下单、修改订单或付费监管快照入口。源代码使用仓库 LICENSE，外部数据仍受各来源授权条件约束。

## 本版范围

| 工作区 | 功能与实际边界 |
|---|---|
| 组合与策略 | 现金股票流水、策略 FIFO、多币种历史汇率、现金事件与拆股、对账；金额使用六位定点数 |
| 公司研究 | SEC 财务事实、历史披露日期、基本面与估值、来源链接；目前正式自动财报覆盖 SEC 发行人 |
| 图表与估值 | 日线、组合历史曲线、DCF、现金股票压力情景；收益曲线采用日末外部现金流近似 |
| 衍生品对冲 | 独立的单币种假设组合，股票、欧式期权、线性期货，Delta/Gamma/Vega/Theta，价格/波动率/时间全量重估，方案版本保存 |
| 保证金 | 从当前设备 IBKR 会话读取账户汇总，逐项保留币种、券商时间戳、未知与过期状态；剩余流动性 / 净清算值仅在币种、时间一致时计算 |
| 宏观 | 世界银行 WDI：10 个国家/地区的年度名义 GDP、实际增长、CPI 通胀；2010–2025，保存抓取版本 |
| 新闻与研究 | 美联储官方 RSS、手动导入新闻、公司研究笔记 |
| 数据中心 | SEC/日线/IBKR 查询、导入与导出、设备绑定的网关设置、浏览器登录入口与登出 |

“全球市场”表示 IBKR 可搜索市场和目前列出的宏观国家，不表示免费数据覆盖所有交易所实时行情、所有公司的标准化全球财报。券商权限、行情订阅和登录要求仍适用。

## 必须正确理解的模型边界

衍生品是假设情景工作台，未将期权/期货交易混入现金股票 FIFO 账本。模型期权仅接受欧式、正波动率和正初始剩余期限；到期情景取内在价值。数量是股票股数或衍生品合约张数，乘数须由用户根据真实合约填写。期货冲击作用于合约价格，不估算基差、展期、资金成本或交割。

保证金显示券商报告值，不能替代完整组合保证金引擎，也不推断强平价格。过期阈值 120 秒，最低手动刷新间隔 10 秒；10% 比例只是本地提醒阈值。未知数据保持未知，`isNull=true` 不能当作零；不叠加证券和商品分项。

WDI 报告期并非发布日期。历史发布日期未知，分析日期只能看到实际抓取日期之前已获取的版本。年度数据不适合作为日内宏观日历。官方新闻按发布日期筛选，历史 RSS 更新并不构成完整逐时新闻档案。

## 数据与设备隔离

- user/demo/test 使用独立数据库；所有自动修改测试先核对 test 环境。
- 测试使用新建的私有 PostgreSQL 集群、独立应用根目录、合成 HTTPS 网关 5001。测试不连接真实网关 5000，不抓取外部公开来源。
- 用户网关配置按本机身份保存；安装和状态不可迁移。账户列表和保证金结果仅作当前页面预览，不写入研究数据库。
- 退出登录会清理本地会话准备状态与账户缓存，即使券商未确认远端退出也不保留本地可查询状态。
- 源码发布包采用文件白名单，不包含 `.local`、数据库、网关、配置、密钥、测试运行报告或用户导出。

## 本地验收

先构建，再运行 CTest 和 `python3 scripts/test-isolated.py`。后者自行创建和销毁隔离服务，不得把集成测试指向真实用户服务。真实网关验收须由用户本人完成登录与双重验证；没有真实会话通过的项目，必须记录为未验收。

发布源码包：`python3 scripts/package-release.py --output /tmp/reachterminal-release`。该操作仅创建本地归档与 SHA256，不创建 Git 标签、推送仓库或公开发布。
